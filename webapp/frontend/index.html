How it works

  1. Module A

    Dataset construction

    RSS feeds plus sitemap and section-page crawling (BeautifulSoup, trafilatura) across Bangla and English Bangladeshi newspapers. Each document stores title, body, date, URL, language and token count.

  2. Module B

    Query processing

    Documents under 20 tokens are removed, and English text is lowercased with whitespace normalized. Query language is detected from the Bengali Unicode block (U+0980–U+09FF).

  3. Module C

    Retrieval

    One BM25 (Okapi) index per language. The English tokenizer strips punctuation; the Bangla tokenizer splits on whitespace.

  4. Module D

    Cross-lingual search

    MarianMT translates the query (opus-mt-bn-en and opus-mt-en-to-bn). The original query searches its own language's index and the translation searches the other.
